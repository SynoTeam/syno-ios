# Syno 제품 배경

상태: Draft
마지막 검토: 2026-10-12

제품 방향을 설명하는 참고 자료입니다. 현재 요청과 실제 구현이 이 문서보다 우선하며, 구현 상태는 코드에서 확인합니다.
개인정보와 자동 수집에 관한 구현 제약은 루트 [AGENTS.md](../AGENTS.md)의 Privacy 절을 따릅니다.

## 개요

Syno는 iOS 우선의 개인 AI 메모리 앱입니다.

화면, 텍스트, 링크, 파일, 사진, 음성 메모, 메일 관련 맥락 등 업무 기억을 저장하고, AI가 사람·회사·프로젝트 중심으로 정리해 검색, 요약, 미팅 브리핑으로 다시 꺼내 쓸 수 있게 합니다.

초기 방향은 iOS 우선입니다. 이후 macOS 캡처 흐름을 확장할 수 있지만, 사용자가 명시하지 않는 한 macOS를 주 대상으로 가정하지 않습니다.

## 제품 우선순위

- 로컬 우선의 저장, 정리, 검색 흐름을 만듭니다.
- 백그라운드 자동 수집보다 사용자가 직접 저장하는 흐름을 우선합니다.
- 원본 데이터와 파생 색인 데이터를 분리합니다.
- OCR 텍스트, 요약, 사람/프로젝트 연결, 출처, 날짜, 후속 조치 같은 파생 메타데이터는 가치가 있으면 보존합니다.
- 민감한 정보는 보수적으로 다룹니다.
- Sensitive Vault 데이터는 사용자가 명시하지 않는 한 기본 검색, 요약, 브리핑에 포함하지 않습니다.

## 방향

- 플랫폼: iOS 우선, macOS는 이후.
- UI: SwiftUI 우선. SwiftUI로 시스템 기능을 다루기 어려울 때만 UIKit이나 플랫폼 API를 씁니다.
- 저장: 로컬 우선. iCloud 동기화는 선택지로 검토합니다.
- AI: OCR/STT 결과를 요약, 분류, 사람/회사/프로젝트 후보, 후속 조치 추출에 씁니다.
- 검색: 로컬 DB와 로컬 색인 검색을 먼저 쓰고, AI 답변 생성은 가치가 있을 때만 씁니다.
- 클라우드: 초기에는 요약, 태그, 링크, 검색 색인, 후속 조치 같은 가벼운 메타데이터에 한정합니다.
